# bedwars

This a bedwars mini game for plasmid, still in developpement, some features are already implemented :
* map loading
* waiting for player before starting 
* scoreboard (which display alive team/splayers)
* bed breaking mecanics and win detection  
* respawn only available when you have a bed
* forge (the resource generator) with split support (each player get the same amount of resources), it stop spawning iron if 64 iron ingots are waitingv(or 16 golds)  
* map claim (you can only breaks blocks placed by a player and can't get too far)  
* various sound and messages feedback  
* colored and upgradable armors   
* old minecraft regeneration  
* configurable shops with support 
* add modded sword which emulate the old pvp, with old damage set  
* over 40 items implemented, such as fireball, launchpad, popup tower and bridge egg
* shopkeepers for item and team upgrades  
* spining cube generator 
* blindness, slowness, mining fatigue and alarm traps are available 
* reconnection available
* fancy player tracker 
* statistics
